# Sistema de animaciones Tharpon MX

## Herramientas propuestas

- Flutter Animate
- Rive
- Animaciones nativas de Flutter

## Duraciones

- Pulsacion de botones: 120 ms
- Elevacion de tarjetas: 180 ms
- Ventanas flotantes: 220 ms
- Cambio de pantalla: 250 ms
- Apertura de menu: 280 ms
- Confirmacion exitosa: 800 ms

## Estados personalizados

- Cargando informacion
- Sin registros
- Sin coincidencias
- Sin conexion
- Error de operacion
- Acceso restringido

Cliente: mascota inspirada en el sabalo.
