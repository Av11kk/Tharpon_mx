# Tharpon MX - Diseño UI/UX

## Version 1.0

Documentacion de las interfaces y prototipos
del proyecto Tharpon MX.

## Aplicacion cliente

- Inicio de sesion y registro
- Recuperacion de contraseña
- Dashboard
- Clima y mareas
- Especies de peces
- Mapa de puntos de pesca
- Consejos
- Catalogo de equipo
- Perfil, capturas, notas y reportes

## Aplicacion administrativa

- Dashboard administrativo
- Productos y categorias
- Promociones
- Consejos y especies
- Puntos de pesca
- Usuarios y reportes
- Configuracion
- Version movil y escritorio
